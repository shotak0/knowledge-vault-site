# knowledge-vault

個人の知識・情報・知見を継続的に蓄積するためのナレッジ管理リポジトリのサイトです。URL を入力として AI が情報を取得・解析し、分類・要約・詳細解説を生成します。単なるブックマーク集ではなく、蓄積した情報を再利用できる知識として整理しています。

## しくみ

- **情報源（Source）**：記事や投稿などの情報源を1件1ファイルで保存したものです。要約と詳細解説が日本語で書かれています。
- **Knowledge**：複数の情報源に共通する概念や原則を、再利用できる知識として整理したものです。Source のコピーではなく、概念・仕組み・活用例を中心にまとめています。
- **Topics**：テーマごとに複数の情報源・Knowledge を横断してまとめたものです。
- **Digest**：週次・月次・年次で、その期間に蓄積された知識の変化を整理したものです。
